# Governance

DatabricksMCP currently uses a maintainer-led governance model. Maintainers are
responsible for releases, security response, roadmap decisions, and repository
access. Technical decisions should be documented in issues or architecture
decision records and resolved by consensus where practical.

As the contributor base grows, this document will define maintainer nomination,
voting, release authority, conflict resolution, and succession procedures.

No contributor or maintainer may represent this project as an official
Databricks product.
